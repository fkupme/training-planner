# Обёртки UI (`src/components/ui/wrappers`)

Совместимые с Vant обёртки для унифицированного API темизации.

## Файлы
- `Cell.vue`, `CellGroup.vue` — ячейки/группы.
- `Field.vue` — поле ввода.

## Шаблон API
- props: `modelValue`, `label`, `placeholder`, `disabled` и др.
- emits: `update:modelValue`, `focus`, `blur`.
