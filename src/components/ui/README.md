# UI Architecture

- components/ui: тонкие обёртки над Vant, чистые презентационные компоненты
- components/: доменные виджеты без роутинга
- pages/: экраны, собирают доменные виджеты и управляют навигацией
- stores/: состояние по доменам (Pinia)
- composables/: переиспользуемая логика (IME/keyboard, insets, форматирование)
- db/: adapters к плагинам Tauri и миграции
- router/: маршруты и гварды

OnboardingPopup — доменный компонент без знании о роутинге: монтируется в App.vue и показывает онбординг, когда профиль неполный.
