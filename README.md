## План разработки (training-planner)

- **Стек**: Tauri 2 (мобайл/десктоп), Vue 3 (TS), Vite, Vant, Pinia, Vue Router, dayjs
- **Хранилище**: tauri-plugin-sql (sqlite локально для офлайна). Позже можно добавить синк.
- **Напоминания**: tauri-plugin-notification (локальные уведомления)

### Этапы

1. Базовая оболочка UI (готово): Vant + Tabbar, роутинг и страницы-заглушки
2. Модель данных и миграции SQLite (локально):
   - Таблицы: programs, workouts, exercises, sets, reminders, intake (supplements/drugs), results, schedules
   - Вспомогательные: notifications_queue
3. CRUD планировщика:
   - Создание сплитов, циклов, «рассинхрон» с днями недели и произвольные интервалы (например 20-дневный цикл)
4. Напоминания:
   - Триггеры по расписанию: тренировки, приёмы (например каждые 4 дня; 2.5 дня)
   - Локальные уведомления; обработка «отложить/выполнено»
5. Журнал результатов:
   - Запись веса/повторов/самочувствия, фильтры по датам/программам
6. Таймер тренировок:
   - Интервальный таймер, паузы между подходами, звук/вибро
7. Полировка UX, экспорт/импорт данных, резервные копии

### Технические заметки

- Capabilities: добавлены `notification:default`, `sql:default`
- Rust: подключены плагины Notification/SQL
- JS: страницы `Planner`, `Reminders`, `Results`, `Supplements`, `Timer`

### Скрипты

- `npm run dev` — запускает Vite (тауритулза поднимет dev)
- `npm run build` — типизация + сборка
- `npm run preview` — предпросмотр
- `npm run tauri` — CLI Tauri
